# Calendar and learning contracts

Choose cadence from actual capacity, audience, and evidence. A one-person
business with one recording hour needs a different plan from a creator team.
Include asset dependencies and approval needs before committing dates.

Suggested calendar fields: draft ID, proposed date/timezone, surface/visibility,
reader need, objective, theme/series, original angle, format, source/permission,
production requirement, status, optional CTA, intended metric.
Status is draft / approved / published only when evidenced by the user or
an authorized external action; this skill itself only drafts a plan.

Experiment card:

- Hypothesis and reason, classified as hypothesis rather than platform law.
- A feasible creative change and otherwise comparable conditions.
- Primary metric with definition, numerator/denominator when applicable.
- Observation age/window, expected sample limitations, and confounders.
- A decision rule selected before looking at results, without false precision.
- A next action for positive, negative, or inconclusive evidence.

Example: compare two opening approaches across several comparable process
demonstrations, using supplied retention at the same publication age. If no
retention is available, choose a genuinely available measure and acknowledge
that it cannot answer the same attention question.

Don't stop a promising theme because one post was weak. Don't keep repeating
a weak format because a heuristic score is high. Return inconclusive findings
when sample/conditions cannot distinguish competing explanations.
