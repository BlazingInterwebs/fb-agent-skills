# Reply triage

| Comment | Default useful response | Boundary |
| --- | --- | --- |
| Genuine question | Answer specifically; cite or ask for context when necessary | No invented technical/business claims |
| Shared experience | Acknowledge the particular detail and add value if available | No fake matching personal story |
| Respectful disagreement | Address the substance and clarify scope | Don't provoke conflict for distribution |
| Praise | Brief sincere acknowledgment or no reply | No mandatory follow-up question |
| Support issue | Recognize the issue and offer a legitimate route | No exposed customer detail or fake resolution |
| Resource request | Provide an existing relevant resource or confirm delivery preference | Don't claim a DM was sent; no unlimited sales consent |
| Suspected spam/abuse | Recommend ignore/report/moderation review as appropriate | Do not execute moderation or state uncertain identity as fact |

For a live discussion, time-sensitive questions can take priority over growth
goals. For business content, a sales-relevant question can be answered without
turning every thread into a funnel. Do not move normal disagreement into DMs
simply to suppress visible criticism.
