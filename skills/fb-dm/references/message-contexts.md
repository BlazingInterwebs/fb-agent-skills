# Message context and consent

Personal Messenger and Page Inbox are different senders and access contexts.
Knowing the Page URL doesn't prove the user has message access. This skill
supports drafts from authorized supplied records, not account operation.

| Context | Draft approach | Check |
| --- | --- | --- |
| Incoming question | Answer it directly and ask only necessary clarification | Is the answer known and appropriate for this sender? |
| Requested resource | Give the actual resource and simple usage context | Does it exist; was private delivery requested or accepted? |
| Existing conversation | Continue the agreed topic with a useful next step | Scope and any prior opt-out |
| Specific collaboration | State a truthful relevant reason, concrete idea, low-pressure ask | No mass templating or false familiarity |
| Support | Acknowledge and route without exposing private identifiers | Don't promise an unverified resolution |
| Follow-up | Add useful context when a follow-up is welcome and appropriate | Stop on decline, opt-out, or no legitimate purpose |

Draft requests do not authorize sending. Resource delivery does not authorize
an unrelated sales sequence. Never claim a tool delivered anything when only
copy was created. Avoid storing full threads when a redacted brief suffices.
