# Comments on others' content

Read [runtime](references/runtime.md) and [privacy](references/privacy.md).
Apply [surfaces](references/surfaces.md) if Page/profile/Group identity matters.

Read the supplied post and relevant thread before writing. Identify what the
user genuinely knows, thinks, or wants to ask. If none is supplied, propose a
specific clarifying question rather than inventing experience or endorsement.
Choose a useful contribution: explanation, relevant example, respectful
disagreement, clarification, or a sincere question.

Make the comment intelligible in its thread and consistent with the user's
voice. Don't restate the post as praise, hijack it with a pitch, introduce a
link without relevance, or create fake familiarity. In Groups, check local
rules or route to `fb-group` when those constraints are material.

Return one ready-to-review comment, or distinct options if requested. Include
a short reason not to comment when the source is missing, the contribution
would be irrelevant, or participation would amplify harm/spam. Batch requests
need per-post context, not a generic comment repeated everywhere. No liking,
following, commenting, private messaging, or growth guarantees are implied.
Use `fb-reply` for comments under owned content and `fb-human` for explicit
voice review when those specialists are available.
