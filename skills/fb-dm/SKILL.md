# Messenger drafting

Read [runtime](references/runtime.md), [privacy](references/privacy.md), and
[message contexts](references/message-contexts.md). Check [surfaces](references/surfaces.md)
when the sender is a Page rather than a person.

Use the relevant conversation, relationship, expressed request, sender identity,
actual offer/resource, and intended outcome. Establish whether this is an
incoming question, an existing authorized conversation, requested delivery,
or a legitimate specific collaboration approach. A reaction, group membership,
or public comment does not automatically authorize unrelated sales messaging.

Draft an individual response that answers the request first. Use only true
context; no fake familiarity, invented mutual connections, or disguised automation.
Offer the smallest appropriate next step. If contact is unwanted or a previous
decline/opt-out exists, recommend stopping. Do not prescribe a universal
follow-up count or continue because silence supposedly signals interest.

For small-batch triage, classify supplied threads as answer, clarify, support,
collaboration, unwanted/spam, or hold; use only necessary private excerpts.
Return per-thread draft and action recommendation. Don't export contacts,
enrich identities, move conversations to another service, send, schedule, or
trigger a keyword delivery system. If an API integration is requested, state
that it is outside this skill and needs separate current permission/window
verification. Never invent that Facebook will allow an automated message.
