# Roadmap and release gates

0.1.0 is a complete bounded pilot, not proof of growth effectiveness.
All 13 capabilities, context templates, examples and export-based helpers are free.

Before 1.0:

- Run permissioned creator/business pilots across profile, professional mode,
  Page and Group contexts. Evaluate usefulness, voice fidelity, factual safety
  and actual host routing; keep private inputs out of public fixtures.
- Validate current composer/Story feature availability and real owner export
  schemas, publishing documented host/version compatibility results.
- Run the behavioral cases with independent evaluators where authorized;
  report failures, model/host versions, and limitations rather than a fake score.
- Test plugin installation on intended hosts; directory approval is a separate
  submission process, not part of publishing source.
- Update dated platform evidence and implement changes only when supported.

Future integrations must have explicit authorization, current verified API
capabilities, opt-outs, safe data boundaries and testable failure modes. Keep
the supplied-data/manual workflow intact. Paid media rendering, autonomous
publishing, broad scraping, unsolicited outreach and ranking predictions are
not implicit roadmap commitments.

Optional services can provide installation support, voice/brand setup, training,
consulting, cross-platform orchestration, or maintained authorized integrations.
Charge for expertise and operations, not by withholding necessary free capabilities.
No telemetry or payment integration is bundled.
