# Architecture and authority

User facts, voice, objectives and permissions
-> a selected Facebook workflow
-> specialist instructions and available helpers
-> a platform-native draft or evidence-backed recommendation.

No master skill is required for ordinary work. Only chain specialists when the
requested deliverable needs it; one post doesn't require a research campaign.

| Capability | Authority | Related handoff |
| --- | --- | --- |
| External examples and outliers | fb-research | Concept to post/video |
| Published-account learning | fb-audit | Evidence to plan/revision |
| Source extraction | fb-repurpose | Briefs to format skills |
| Allocation and growth series | fb-plan | Calendar to selected composition |
| Feed text/image/link composition | fb-post | Humanization when needed |
| Spoken video and Live preparation | fb-video | Audit only with actual results |
| Story sequence | fb-story | Authorized reply to dm |
| Voice revision | fb-human | Return revised requested artifact |
| Group constraints/material | fb-group | Composition after local rules |
| Others' posts / owned threads / inbox | fb-comment / fb-reply / fb-dm | Keep contexts and permissions distinct |
| Profile/professional-mode/Page clarity | fb-presence | Plan/audit when separately requested |

Each `SKILL.md` has a short frontmatter description and operational entrypoint.
Conditional references are loaded when relevant. Canonical common resources
live in `shared/`; `scripts/sync_resources.py` mechanically bundles identical
copies plus licenses inside every skill. Audit/research each receive the same
comparison helper. Every folder can be copied independently without a shared
installation outside that folder. Siblings are optional; fallbacks are explicit.

This intentionally accepts bundled storage duplication to avoid dependency
breakage. CI checks generated copies against canonical source. User-specific
context is runtime input, not a modification of installed methodology.

Audience growth follows the shared growth loop. Research informs topics;
composition earns attention and delivers a payoff; planning/presence provide
reasons to return; engagement serves people; actual evidence drives iteration.
Creative review is not a performance prediction, and no metric grants permission.
